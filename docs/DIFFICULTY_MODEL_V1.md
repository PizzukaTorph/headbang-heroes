# Difficulty Model v1

> Status: baseline difficulty design for Headbang Heroes. Exact timing windows and density thresholds remain playtest/tuning variables.

## Difficulty tiers

Initial tiers:

- Easy
- Normal
- Hard
- Extreme

The same song and the same neck simulation are used across all difficulties. Difficulty changes what the chart asks the player to perform, not the underlying physical rules.

## North-star rule

**Higher difficulty does not make the neck artificially harder to control. It asks the player to control the same neck through harder choreography.**

Do not add hidden difficulty multipliers that make Motion Quality worse or neck dynamics harsher simply because the selected tier is higher.

## What changes with difficulty

Difficulty is defined by several chart-facing variables:

- event density
- maximum rhythmic subdivision
- technique vocabulary
- trajectory changes
- modifier usage
- timing-window tolerance
- momentum-planning demand
- authored/rest spacing

These should work together rather than relying only on more events per second.

## Rhythmic density and subdivision

Higher difficulty may describe progressively finer rhythmic detail from the same song.

Baseline target:

- **Easy**: up to quarter-note pulse (`1/4`)
- **Normal**: up to eighth-note detail (`1/8`)
- **Hard**: up to sixteenth-note detail (`1/16`)
- **Extreme**: may use thirty-second-note detail (`1/32`)

This is a capability ceiling, not a requirement to fill every passage at the maximum subdivision.

If the music contains a long sustained phrase, the chart should remain spacious even on Extreme.

Example interpretation of the same dense musical passage:

```text
Easy     -> skeleton pulse / major quarter-note landmarks
Normal   -> main groove / eighth-note structure
Hard     -> detailed sixteenth-note performance
Extreme  -> full-detail interpretation, including 1/32 where musically justified
```

## Chart philosophy

The four difficulties should not be generated by mechanically deleting every second event from one master chart.

Each difficulty should be an intentional interpretation of the same music:

- **Easy**: rhythmic skeleton
- **Normal**: primary groove
- **Hard**: detailed performance
- **Extreme**: complete / virtuosic interpretation

All versions must still feel authored to the song.

## Technique mix

Technique vocabulary expands with difficulty.

### Easy

Primarily:

- Classic Horizontal
- occasional Classic Vertical
- Rest

Goal: teach timing, inversion and momentum without vocabulary overload.

### Normal

Adds:

- Classic Horizontal / Vertical
- Half
- introductory Deep
- simple modifiers where useful
- Rest

### Hard

May use:

- Classic
- Half
- Deep
- Whiplash
- introductory Windmill
- broader use of Double / Hold / Accent
- more frequent trajectory changes
- Rest

### Extreme

May use the complete supported neck vocabulary:

- Classic
- Half
- Deep
- Whiplash
- Windmill
- Rest
- full trajectory vocabulary
- Double / Hold / Accent / Burst
- fast technique and trajectory transitions

New mechanics should still respect the existing Technique + Trajectory + Modifier grammar.

## Timing windows

Timing-window tolerance becomes tighter with difficulty.

Important distinction:

- **Subdivision/density** determines how frequently authored actions occur.
- **Timing window** determines how precisely the player must act around an authored event.

Extreme may therefore combine dense 1/32 passages with narrower PERFECT/GREAT windows, but these are separate tuning dimensions.

Exact millisecond thresholds are intentionally not fixed in this document. They must be tuned through real-device playtesting.

All timing-window values must be data-driven/configurable rather than hardcoded across gameplay logic.

## Motion demand

Motion demand is not a separate artificial stat applied by difficulty.

It emerges from chart choreography.

A sparse pattern gives the neck time to build amplitude and momentum:

```text
LEFT ---------------- RIGHT
```

A dense pattern may require rapid reversals or trajectory changes:

```text
LEFT -> RIGHT -> LEFT -> UP -> DOWN
```

The second pattern naturally demands better control of:

- momentum
- inversion timing
- travel distance
- preparation
- technique choice
- recovery

This is where Half/Burst and other techniques become useful: they are not arbitrary difficulty tax, but tools for handling physically denser choreography.

## Motion Quality fairness

Motion Quality remains the same concept on every difficulty.

Do not lower a player's Motion Quality merely because the chart is Extreme.

Instead, Extreme should create situations where producing high Motion Quality is naturally harder because there is less time and more demanding movement sequencing.

## Rest

Rest remains part of every difficulty.

Do not define Extreme as constant movement without musical breathing room.

### Natural Rest

Sections with no authored required action may become more or less frequent depending on how much rhythmic detail a difficulty includes.

Easy may naturally contain more empty space because it charts fewer secondary events.

### Authored Rest

Musically meaningful authored Rest should remain present across difficulties when the song calls for stillness/recovery.

A musical stop remains a stop.

Rest is part of the performance grammar, not dead time.

## Momentum planning

Difficulty should increasingly test the player's ability to prepare future movement.

Approximate progression:

- Easy: simple left/right or vertical preparation
- Normal: momentum awareness becomes useful
- Hard: momentum planning becomes important
- Extreme: momentum planning becomes fundamental

The CURRENT/NEXT UX exists specifically to support this skill without turning the game into a note highway.

## Direction and trajectory changes

Higher difficulty may increase:

- reversal frequency
- horizontal/vertical switching
- circular transitions
- CenterEdge transitions
- technique changes inside dense phrases

These changes should always remain musically motivated and readable through the established visual grammar.

## Modifier density

Modifiers should also scale with difficulty.

Suggested direction:

- Easy: almost none
- Normal: occasional/simple modifiers
- Hard: regular use where musically appropriate
- Extreme: full modifier vocabulary and denser combinations

Avoid modifier spam that reduces readability or turns authored choreography into arbitrary complexity.

## THE BANG across difficulty

THE BANG follows the same rules on every difficulty:

- build HYPE
- reach READY
- manually tap HYPE
- enter THE BANG
- execute the Finisher opportunity when valid

No separate difficulty-specific control scheme or THE BANG rules are introduced.

A denser chart may generate more raw HYPE opportunities, but progression/reward systems should normalize where necessary so Extreme does not automatically become the best way to farm XP/HH solely because it contains more events.

Gameplay HYPE and meta rewards may therefore be balanced separately.

## Difficulty summary

| Dimension | Easy | Normal | Hard | Extreme |
|---|---|---|---|---|
| Max subdivision | 1/4 | 1/8 | 1/16 | 1/32 |
| Event density | Low | Medium | High | Very high |
| Technique mix | Minimal | Core | Broad | Full |
| Trajectory changes | Simple | Moderate | Frequent | Aggressive |
| Modifier usage | Minimal | Light | Broad | Full |
| Timing tolerance | Wide | Standard | Tight | Very tight |
| Momentum planning | Introductory | Useful | Important | Fundamental |
| Rest | Yes | Yes | Yes | Yes |
| THE BANG rules | Same | Same | Same | Same |

## Data-driven tuning

The following must remain configurable:

- max subdivision per difficulty
- timing windows per judgment
- chart-density targets/guidelines
- allowed techniques
- allowed trajectories
- allowed modifiers
- tutorial/introduction gates for techniques
- HYPE/reward normalization parameters

Do not scatter difficulty constants across gameplay code.

## Acceptance criteria

A difficulty implementation is successful when:

- Easy teaches the core inversion/momentum loop without overwhelming the player
- Normal represents the song's main groove
- Hard requires active momentum management and broader technique usage
- Extreme can express the song at full-detail rhythmic density, including 1/32 passages where musically justified
- higher difficulty never changes neck physics solely to make control harder
- timing windows and rhythmic density remain distinct tuning variables
- Rest remains musically present at all levels
- all four charts feel intentionally authored rather than mechanically thinned copies
- THE BANG remains mechanically consistent across difficulties
