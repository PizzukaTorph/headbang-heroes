# Visual Direction v0.1

Status: **approved reference direction**

## Core synthesis

Headbang Heroes combines:
- Clean Dark Cartoon for gameplay readability
- Metal Comic for texture, typography and attitude
- Grotesque Cartoon for HYPE escalation, bosses and finishers

Shorthand: **A baseline + B identity + C escalation**.

The visual north star is dark, adult, exaggerated metal-animation energy, while characters, environments, UI and distinctive design language remain original to Headbang Heroes.

## Gameplay composition

- portrait mobile
- near-frontal 3/4 avatar
- avatar occupies roughly 50–60% of useful height
- head-centered closing timing circle
- minimal active HUD: score, combo, HYPE
- dark/static layered venue art with restrained motion/FX
- rhythm information always wins contrast/readability priority

## Performance framing language

Headbang Heroes deliberately distinguishes baseline rhythm from Technique Skills
through framing:

- **Classic:** tighter gameplay framing; head, neck and upper body dominate.
- **Technique Skill:** rapid camera-style pull-back; full silhouette becomes
  visible for the authored performance.
- **Return:** soft settle back into the Classic crop.

Initial transition target is 100–150 ms outward and roughly 200 ms back. The
effect must feel like a performance accent, never like a UI zoom or a gameplay
timing signal.

The avatar may change framing; rhythm UI does not. CURRENT/NEXT, gesture guides,
score, combo and HYPE remain stable in screen space.

## Character escalation

**IDLE → BANG → COMBO → HIGH HYPE → MAX HYPE / POSSESSED**

Animation and deformation communicate performance quality. Hair is a primary secondary-motion surface, but all hair choices including bald/short styles remain competitively equivalent.

## Avatar system

Identity presentation:
- Male
- Female
- Other

Face archetypes:
- 5 per presentation set target

Body archetypes:
- S / Slim
- M / Medium
- L / Large
- XL / Extra Large

Modifiers:
- facial hair
- piercings
- makeup
- tattoos
- Special original metal-themed treatments

Hair:
- broad length/style/color catalog
- strong secondary motion where applicable

Apparel:
- headwear
- tops/shirts
- jackets/vests
- bottoms
- footwear
- accessories

Apparel is a primary HH currency sink and future content surface.

## Art-production constraint

Keep the number of rigs/body families controlled. Favor a shared skeleton and modular apparel strategy. Do not create a system where every cosmetic requires bespoke animation for every avatar combination.

## Reference usage

Concepts are visual targets, not shippable assets. Use them to judge composition, readability, proportion, deformation range, customization breadth and brand tone.
