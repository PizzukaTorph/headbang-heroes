# Headbang Heroes avatar references

These images are reference material for the first Headbang Heroes avatar.

- `headbang-heroes-avatar-reference-original.jpeg`: modular metal avatar with the initial styling direction.
- `headbang-heroes-avatar-reference-clean-base.png`: neutral base version for the prototype and for future handoff to game artists.

The clean base is the current PoC asset direction: plain black shirt, long hair, readable neck and shoulders, and no costume-specific accessories.
